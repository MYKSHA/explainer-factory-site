Explainer Factory is a private publishing tool used by one creator to upload, schedule and track explainer videos on their own YouTube channels:

  • Atlas Power: geopolitics and maps
  • Bharat Wealth: personal finance for India
  • Chronos Dark: history
  • Cosmica Tech: technology explainers
  • Sapien Sense and Sapien Sense Hindi: psychology

The tool uses the YouTube Data API to upload videos, set titles, descriptions, thumbnails and publish times, and the YouTube Analytics API to read view and audience statistics for these channels only. It is not offered to the public and has no user sign-up.
